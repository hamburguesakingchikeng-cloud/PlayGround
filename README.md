## Street Clash — Neon Rooftop Duel

A self-contained 2D fighting game built with HTML, CSS, and Canvas. No dependencies, no build step.

- **Best of three** rounds on a neon rooftop stage, against a reactive CPU opponent.
- **Three special moves** — each costs 25 SP and can be triggered by motion input or a dedicated key/button:
  - **Hadoken** — `↓↘→ + J` (fireball)
  - **Shoryuken** — `→↓↘ + J` (invincible rising uppercut)
  - **Tatsumaki** — `↓↙← + K` (advancing spinning kicks, 3 hits)
- Basic attacks build SP. Hitstop, screen shake, combo scaling, chip damage, projectiles, and KO slow-motion are included.
- Touch controls appear on phones and tablets. Landscape is recommended for the biggest arena.
- Sound effects are synthesized with the Web Audio API; press `M` or the ♪ button to mute.

**Desktop controls:** `A/D` move · `W` jump · `S` block · `J` punch · `K` kick · `1/2/3` specials · `P/Esc` pause

**Run:** `PORT=3002 ./start.sh` and open `http://localhost:3002`.
